# 试题转换台

一个纯前端的试题格式转换工具：把 Word 试题文件（.docx）或直接粘贴的试题文字，
自动识别单选/多选/判断题，转换成符合"考试系统导入模板"格式的 Excel 文件。

## 在线使用

部署到 GitHub Pages 后，直接访问本仓库对应的 Pages 地址即可使用，
例如：`https://你的用户名.github.io/仓库名/`

## 重要说明：数据隐私

虽然这个页面是通过网络访问的，但**所有的文件解析、试题识别、Excel
生成，都在你自己的浏览器本地完成**，页面本身不会把你的试题内容发送到
任何服务器。可以在浏览器开发者工具的"网络"面板里自行验证：解析和导出
过程中不会有任何数据请求。

## 为什么需要部署到网上（而不是纯本地文件）

工具最初是一个可以离线双击打开的单文件 html，但在钉钉/微信这类 App
内置的"文件预览"环境里，浏览器的文件下载功能会被拦截，且部分设备上
连"用浏览器打开"的分享选项都没有。把它部署成一个正式网址后，可以直接
用手机自带的 Safari / Chrome 浏览器访问，彻底绕开这个限制。

## 本地使用

如果不需要在钉钉/微信里用，仓库里的 `index.html` 本身仍然是一个完整
可用的离线单文件工具，可以直接下载到本地双击打开，或放进 U 盘使用，
不需要部署也能用。

## 更新工具

以后如果需要更新解析规则或功能，直接替换仓库里的 `index.html` 文件，
提交（commit）后 GitHub Pages 会在几十秒到几分钟内自动更新线上版本。
